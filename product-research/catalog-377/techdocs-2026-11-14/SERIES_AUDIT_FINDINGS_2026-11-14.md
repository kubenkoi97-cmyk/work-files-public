# Проверка группировки 377 товаров без заливки — 14.11.2026

## Вывод
**53 папки версии v6/v7 — предварительные группы по кодам моделей (SKU-families), а не 53 независимо подтверждённые коммерческие серии производителя.**
Проверен только исходный набор **377** товаров без заливки в `Каталог 744`; окрашенные **367** товаров исключены. В исходном наборе уникальны все 377 пар `бренд + модель`. По исходным наименованиям не обнаружено смешения разных основных типов блоков в одной кодовой группе.

## Ошибки и оговорки классификации
1. **IGC IMS_BH**: одна линейка BH, но 2 модели `IMS-BH220NH(DC)`, `IMS-BH280NH(DC)` и 2 модели `IMS-BH450NB`, `IMS-BH560NB` — отличающиеся исполнения. Технические PDF текущего комплекта содержат точные модели только для первой пары. Пара NB не может наследовать без проверки цифровые характеристики NH(DC). В отчёте сохранены обе подгруппы как разновидности одной BH-линейки.
2. **Midea MI2_G / MI2_G_DP**: две рабочие папки обозначают обычную модель и вариант с дренажной помпой. **В документации производителя они представлены общей линейкой MI2_GDHN18(At)/MI2_GDHN18(At)DP.** Для окончательной упаковки по серии разумно сделать общий комплект с отдельным учётом опции DP и без дублирования общих файлов. Это структурная избыточность, а не доказательство равенства параметров моделей.
3. **Midea MIH_G / MIH_G_DP**: каталожные страницы пересекаются; суффикс DP сохранять обязательно. Допускается общий источник, но привязку технических чисел проверять отдельно.
4. **Kentatsu KTA_HFAN1 / KTA_HZAN1**: два варианта одного префикса, общая каталожная страница показывает и HFAN1, и HZAN1. Нельзя автоматически выбирать общие характеристики без проверки суффикса и столбца.
5. **Номенклатура верхнего уровня**: для Kentatsu группировать под DX PRO Basic (7 групп), DX PRO VII (9), DX PRO A (10), для Midea под ATOM B и V8; сохранять точные кодовые подсемейства внутри. Это более понятная иерархия, чем плоские 53 папки.

## Серьёзная ошибка источника (исправлено в v7)
Из активного архива удалён зарубежный PDF `Midea_ATOM_2024` и 4 вырезки из него. Для `MI2-15Q4CDHN18(At)` в международном каталоге указано **4.5 kW**, а российская карточка MirCli содержит **1.5 kW**. Ввиду несовместимого обозначения мощности применять зарубежную таблицу к российскому исходному перечню опасно. Оригинальный предыдущий ZIP v6 исторически сохранён, но не является рекомендованной текущей версией.
