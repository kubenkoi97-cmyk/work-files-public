# Подлинные HTML-страницы и полнота содержания — отдельные статусы

Всего **377** уникальных SKU. **355** оригинальных HTML с фотографиями фактически получены и проверены. Из них **315** имеют самостоятельное описание в карточке продавца, а **40** — содержат характеристики и фото без отдельного описания.

**10** HTML относятся к неподходящему суффиксу и изолированы; **12** пока не имеют точного HTML.

См. [поартикульную матрицу](./html_capture_matrix.csv). Неполное описание продавца нельзя исправлять подменой оригинала текстом из PDF.
