# Catalog-377 — исходные HTML-карточки товаров

Источник инвентаря: пользовательский Excel «Товары для наполнения Илья.xlsx», лист «Лист1», строки 2–378. Состав: **377 уникальных пар бренд + артикул** — Kentatsu 213, Midea 103, IGC 52, Daikin 8, Bosch 1. Файл Excel не изменён.

## Задание
1. Сначала **mircli.ru**, если там нет точной модели — поиск других общедоступных карточек с **тем же артикулом**.
2. Не заменять модель «похожей» серией/модификацией.
3. Сохранять оригинальный HTML ответа сайта, второй HTML с локальными ссылками на ресурсы, локальные файлы фотографий, manifest.json и ссылку на источник.
4. В каждом пакете — ZIP и CSV статусов, опубликованные в GitHub Releases.
5. COMPLETE = точная карточка с подтверждёнными **описанием, характеристиками и скачанными фотографиями**. PARTIAL/NOT_FOUND/ERROR не считать готовыми.

## Формат архива
`products/BRAND_MODEL/original.html` — полученный с сайта оригинальный HTML;
`products/BRAND_MODEL/offline.html` — копия для просмотра со скачанными локальными ресурсами;
`products/BRAND_MODEL/page_files/` — реальные файлы изображений/стилей/скриптов;
`products/BRAND_MODEL/manifest.json` — источник, точность совпадения и результаты проверки;
`status.csv`, `summary.json` — контроль этапа.

Ограничение: HTML ответа сервера не тождественен снимку динамической страницы после JavaScript. Внешние сайты могут блокировать автоматическую загрузку; такие случаи должны быть явно помечены, а не выдаваться за успех.
