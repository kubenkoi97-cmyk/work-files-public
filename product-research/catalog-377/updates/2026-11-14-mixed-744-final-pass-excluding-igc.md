# MIXED 744 — финальный адресный добор без IGC (14.11.2026)

**Статус:** финальный адресный проход по найденным точным источникам выполнен; исчерпывающий web-pass по *каждому* оставшемуся пустому полю **не доказан**, поэтому Excel нельзя выдавать за 100%-но верифицированный по всем параметрам.

## Область
- Всего 744 товара, 377 изначально без заливки.
- Исключены по новой команде пользователя **52 IGC** (в запросе написано EGC; среди брендов каталога имеется IGC, отдельного EGC нет).
- Продолжена обработка **325 незалитых**: Kentatsu 213, Midea 103, Daikin 8, Bosch 1.
- **367 цветных строк** исключены.

## Подтверждённый результат
- **33 новых значения по 31 точной модели** в рамках этого этапа: 24 записи продавцом площади обслуживания (м²), 7 подтверждённых цветов белых *настенных* блоков, 2 точных размера панелей кассетных Midea V8.
- **280 новых ранее пустых ячеек относительно исходного XLSX** (247 из предыдущих этапов + 33 текущего).
- Внешний XML-аудит исходного XLSX → результата: **0 переписанных ранее непустых ячеек, 0 изменений цветных строк, 0 изменений заливок/стилей**. При сравнении v3 → v4: **0 изменённых строк IGC**.
- Книга включает 744 исходных товара, 16 листов; «Финальный добор 325» — все 33 точных изменения с прямыми ссылками на источник; «Контроль без IGC 4» — ограничения; существующий «Наполнение IGC» 56-колоночный исторический свод для 377 строк обновлён только для 31 не-IGC модели.

4. Длина трассы и температурные пределы зависят от VRF-наружной системы: не приписывать внутреннему блоку чужие внешние характеристики.
