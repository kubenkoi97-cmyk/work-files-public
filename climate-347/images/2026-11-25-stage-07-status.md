# Этап 7 — повторная проверка исходных HTML
Повторно распакованы пять 7z; найдено 387 HTML-файлов (включая вспомогательные HTML). Проверены 68 моделей без рабочего JPG. Для 64 моделей найдена точная карточка и локальный растровый файл, для четырех IGC (IWF-Q1700CAQ4T22, IWF-Q1700CAQ4T44, IMBR-C440ANB, IMBR-H440ANB) точный код отсутствует во всех 387 HTML при поиске ASCII без учета регистра. IMBRG не считать IMBR. 403 связи модель–растр, 62 уникальных исходных растров SHA256 (включая нетоварные и миниатюры), 4 записи без локального изображения. Первичные кандидаты из точной карточки не равны подтвержденным фото.
Визуальный первичный отбор уникальных растров: 152 записи миниатюр, 105 нетоварных изображений, 54 фрагментов или многомодульных изображений с непроверенным составом, 10 водяных знаков, 82 полноразмерных кандидата с неподтвержденным корпусом, 4 без точного HTML. Статусы предварительного отбора не означают полную проверку v11.
