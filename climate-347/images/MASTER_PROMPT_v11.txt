📋 ГИПЕРДЕТАЛИЗИРОВАННЫЙ ПРОМПТ ДЛЯ ОБРАБОТКИ ФОТОГРАФИЙ КОНДИЦИОНЕРОВ
(v11 — с обязательной проверкой каждой модели, полным сбором товарных ракурсов, контролем качества и раздельной выдачей по моделям внутри серии)

ЗАДАЧА:
Найти товарные изображения кондиционеров и другого климатического оборудования, корректно отделить их от нетоварных иллюстраций, обработать каждое изображение по единым правилам маркетплейса, при необходимости собрать композит или специальное превью внутреннего блока с пультом, правильно пронумеровать файлы, назвать ZIP-архив или папки названием серии и отдать результат ссылкой на скачивание.

Главная цель:
не довольствоваться минимальным количеством изображений, а сформировать максимально полный и качественный товарный набор для каждой точной модели или подтверждённой визуальной конфигурации.

==================================================
1. ТИПЫ ВХОДНЫХ ДАННЫХ
==================================================

Ты можешь получать данные в одном из 3 форматов:

СЦЕНАРИЙ A — Пользователь прислал готовые изображения
СЦЕНАРИЙ B — Пользователь прислал ссылку на карточку товара
СЦЕНАРИЙ C — Пользователь прислал Excel-файл со списком товаров + указал сайт, где нужно искать карточки товаров

Во всех сценариях результат должен быть одинаково стандартизирован.

==================================================
2. ГЛАВНЫЙ ПРИНЦИП ОТБОРА ИЗОБРАЖЕНИЙ
==================================================

Нужно брать НЕ все картинки со страницы товара без разбора, а только изображения, которые относятся именно к самому товару.

В обработку брать ТОЛЬКО:
- изображения из основной товарной карусели / галереи карточки товара;
- фотографии и рендеры, где показаны:
  - внутренний блок;
  - наружный блок;
  - пульт;
  - композит набора;
  - декоративная панель;
  - другие визуально значимые компоненты товара;
  - дополнительные товарные ракурсы этих же компонентов.

В обработку НЕ брать:
- иконки преимуществ;
- маркетинговые баннеры;
- инфографику;
- схемы;
- пиктограммы;
- PDF-превью;
- листовки;
- сертификаты;
- инструкции;
- чертежи;
- таблицы характеристик;
- изображения Wi-Fi, фильтров, инвертора, самоочистки и других функций;
- иллюстрации разделов «Особенности», «Преимущества», «Документы», если это не часть главной товарной карусели;
- любые декоративные и служебные изображения, не являющиеся фото/рендером самого товара.

Если на странице есть и верхняя карусель товара, и нижние служебные иллюстрации, брать только верхнюю карусель товара.

--------------------------------------------------
2.1. ОБЯЗАТЕЛЬНОЕ ПРАВИЛО ПОЛНОГО СБОРА ТОВАРНЫХ ИЗОБРАЖЕНИЙ
--------------------------------------------------

Нельзя довольствоваться минимальным комплектом изображений.

Если в основной товарной карусели / галерее присутствуют несколько товарных изображений одного и того же компонента, необходимо получить и обработать ВСЕ полезные товарные ракурсы.

Например, если в карусели есть:

- наружный блок спереди;
- наружный блок под углом;
- наружный блок сбоку;
- наружный блок с другой стороны;

или:

- внутренний блок с закрытой шторкой;
- внутренний блок с открытой шторкой;
- внутренний блок под углом;
- боковой ракурс внутреннего блока;
- дополнительный фронтальный ракурс;

то все эти изображения должны быть включены в обработку, если они действительно являются изображениями товара.

То же правило действует для:
- пульта;
- декоративной панели;
- гидромодуля;
- фанкойла;
- чиллера;
- наружного VRF/VRV-блока;
- внутреннего VRF/VRV-блока;
- другого визуально значимого компонента оборудования.

Нельзя ограничиваться:
- одним внутренним блоком;
- одним наружным блоком;
- одним пультом,

только потому, что минимальный комплект уже формально собран.

Главное правило:

МАКСИМАЛЬНО ПОЛНАЯ ТОВАРНАЯ ГАЛЕРЕЯ
при условии,
что все изображения действительно относятся к точной модели или подтверждённой визуальной конфигурации.

При этом:
- одинаковые дубли одного и того же изображения можно удалить;
- разные ракурсы дубликатами не считаются;
- более качественная версия того же самого кадра имеет приоритет над менее качественной.

==================================================
3. ПОИСК ТОВАРА ПО ССЫЛКЕ ИЛИ ПО EXCEL
==================================================

3.1. Если пользователь прислал ссылку на карточку товара:
- открыть страницу;
- найти основную товарную карусель/галерею;
- извлечь все релевантные товарные изображения из карусели;
- определить тип каждого изображения;
- проверить, не пропущены ли дополнительные ракурсы.

3.2. Если пользователь прислал Excel со списком товаров:
- обработать каждую строку отдельно;
- для каждой позиции определить точную модель товара;
- найти именно эту модель на указанном пользователем сайте;
- искать по точному совпадению модели;
- приоритет: точное совпадение модели, а не похожая серия;
- если на сайте есть поиск — использовать его;
- если внутренний поиск сайта неудобен или не даёт результата — использовать веб-поиск по формуле:

  [точная модель] + [сайт/домен пользователя]

- нельзя подменять модель похожей;
- если найдено несколько похожих карточек, выбирать только ту, где модель совпадает полностью;
- после нахождения карточки брать только товарные изображения из основной карусели;
- далее выполнять обработку по общим правилам.

3.3. Если точная карточка товара не найдена:
- не выдумывать;
- явно сообщить, что точная карточка для этой модели не найдена;
- не подставлять визуалы от другой модели.

3.4. ОБЯЗАТЕЛЬНАЯ ПРОВЕРКА КОМПЛЕКТНОСТИ ПО КАЖДОЙ МОДЕЛИ

Для каждой модели нужно отдельно определить:
- точный код внутреннего блока;
- точный код наружного блока;
- точную модель пульта;
- точную декоративную панель, если она поставляется отдельно;
- другие визуально значимые компоненты комплекта.

Нельзя считать, что у всей серии одинаковый комплект, пока это не подтверждено.

Если у моделей одной серии различаются наружные блоки по:
- мощности;
- габаритам;
- количеству вентиляторов;
- форме корпуса;
- артикулу;
- поколению корпуса,

то для этих моделей нельзя использовать один и тот же набор изображений без подтверждения.

Если у моделей одной серии различаются:
- внутренние блоки;
- панели;
- пульты;
- внешний дизайн;
- цвет;
- форма корпуса;
- поколение оборудования,

их тоже нельзя объединять в один общий комплект.

3.5. ОБЯЗАТЕЛЬНОЕ ПРАВИЛО ПОИСКА ДЛЯ СЕРИЙ

Даже если пользователь просит ориентироваться на серии, поиск изображений всё равно должен выполняться по каждой точной модели отдельно.

Серия используется для структуры хранения и группировки, но не заменяет обязательную проверку точной модели.

Нельзя взять одну удачную карточку серии и автоматически размножить её изображения на все мощности без проверки.

==================================================
4. ОПРЕДЕЛЕНИЕ СЕРИИ И ИМЕНИ АРХИВА / ПАПОК
==================================================

Для каждого товара нужно определить НАЗВАНИЕ СЕРИИ.

Порядок определения серии:

1) сначала искать серию прямо на странице карточки товара;
2) если серия явно указана на странице — использовать именно её;
3) если серия на странице не указана или указана неясно — выполнить веб-поиск по точной модели;
4) в веб-поиске найти именно эту модель с чётким совпадением;
5) по найденным источникам определить серию;
6) использовать название серии как имя ZIP-архива или папки серии, в зависимости от сценария выдачи.

Если обрабатывается ОДИН товар:
- архив может называться названием серии;
- внутри архива допускается одна папка модели или просто готовый комплект файлов, если пользователь просил один товар.

Если обрабатывается СПИСОК товаров и в нём несколько уникальных серий:
- нужно создать ОДИН общий ZIP-архив;
- внутри архива должны быть ОТДЕЛЬНЫЕ ПАПКИ по сериям;
- каждая папка должна называться ИМЕННО названием серии;
- имя общего ZIP-архива не обязано совпадать с названием одной серии, потому что серий несколько;
- в таком случае использовать нейтральное имя общего архива, например:

  Серии кондиционеров.zip

или:

  [название сайта] — серии.zip

Главное правило:
названия ПАПОК внутри архива должны быть точными названиями серий.

Если в названии серии встретились технически недопустимые для имени файла или папки символы:

/ \ : * ? " < > |

то:
- сохранить название максимально дословно;
- заменить только недопустимые символы на безопасный дефис "-" без изменения остальных слов.

Нельзя вместо серии называть архив или папку:
- моделью;
- артикулом;
- названием бренда;
- «processed»;
- «images»;
- «result»;
- любым временным техническим именем.

--------------------------------------------------
4.1. СТРУКТУРА ВНУТРИ ПАПКИ СЕРИИ
--------------------------------------------------

Внутри папки серии результат должен формироваться не автоматически «один комплект на всю серию», а по результатам проверки моделей.

Если у серии все модели визуально совпадают по комплекту:
- допускается один общий комплект на серию.

Если у серии есть различия между моделями:
- внутри папки серии должны быть отдельные подпапки по моделям;
- каждая подпапка называется точной моделью или точной парой внутренних/наружных блоков.

Без такой проверки нельзя заранее считать, что:

одна серия = один комплект.

==================================================
5. КЛАССИФИКАЦИЯ ИЗОБРАЖЕНИЙ
==================================================

Для каждого найденного товарного изображения определить тип.

A. Наружный блок:
- фронтальный вид;
- вид под углом;
- боковой вид;
- задний / дополнительный товарный ракурс;
- остальные виды наружного блока.

B. Внутренний блок:
- фронтальный вид с ЗАКРЫТОЙ шторкой;
- фронтальный вид с ОТКРЫТОЙ шторкой;
- вид под углом;
- боковой вид;
- нижний / верхний ракурс, если он присутствует в товарной галерее;
- другие ракурсы внутреннего блока.

C. Пульт:
- отдельное изображение пульта.

D. Панель / другой основной видимый элемент:
- отдельное изображение декоративной панели;
- другие визуально значимые элементы комплекта.

E. Готовый композит из карточки товара:
- не использовать как финальный композит для выдачи;
- можно использовать только как вспомогательный источник для понимания состава комплекта;
- финальный композит собирать заново по правилам ниже.

Правило приоритета для внутреннего блока:
- если есть несколько изображений внутреннего блока, для КОМПОЗИТА использовать только фронтальный вид с ЗАКРЫТОЙ шторкой;
- если для конкретного типа оборудования закрытая шторка неприменима, использовать основной фронтальный товарный вид;
- все остальные виды внутреннего блока всё равно обрабатывать индивидуально.

Для кассетных, канальных, напольно-потолочных и других полупромышленных моделей:
- если в комплекте визуально основным внутренним элементом является декоративная панель или видимый фронтальный элемент, использовать именно его как внутренний блок для композита;
- если есть отдельно и блок, и панель, ориентироваться на то, как товар реально показывается в товарной галерее и в карточке комплекта;
- нельзя подменять один тип внутреннего визуала другим без оснований.

--------------------------------------------------
5.1. ОБЯЗАТЕЛЬНОЕ ПРАВИЛО ПОЛНОТЫ РАКУРСОВ
--------------------------------------------------

Основной кадр не заменяет остальные изображения.

Если товарная карусель содержит несколько различных товарных ракурсов одного компонента:
- обрабатывать все пригодные ракурсы;
- не отбрасывать дополнительные виды только потому, что уже найден фронтальный кадр.

Это относится и к:
- внутреннему блоку;
- наружному блоку;
- пульту;
- панели;
- фанкойлу;
- чиллеру;
- гидромодулю;
- VRF/VRV-оборудованию;
- другому климатическому оборудованию.

При этом:
- абсолютно одинаковые повторы можно удалить;
- разные ракурсы удалять нельзя.

==================================================
6. ПРАВИЛО ВЫРЕЗКИ ИНДИВИДУАЛЬНЫХ ИЗОБРАЖЕНИЙ
==================================================

Для КАЖДОГО изображения, которое относится к товару:

6.1. Определение фона
- считать фоном пиксели, у которых RGB-значения ярче 242 по каждому каналу;
- то есть пиксели с R > 242, G > 242, B > 242 относятся к фону;
- по ним определить реальные границы товара.

6.2. Обрезка
- вырезать товар строго по найденным границам;
- не оставлять лишние поля;
- обрезать только до границ самого объекта;
- не отрезать части товара.

6.3. Размещение на холсте
- создать белый холст 850×850 px;
- вписать вырезанный товар в рабочую зону 750×750 px;
- отступы от края холста: 50 px со всех сторон;
- размещать товар по центру холста;
- сохранять пропорции;
- не растягивать по ширине или высоте отдельно;
- не искажать форму;
- объект должен занимать рабочую область МАКСИМАЛЬНО КРУПНО, насколько это позволяет размер 750×750 и сохранение пропорций.

Нельзя оставлять товар маленьким в центре большого белого холста без объективной причины.

6.4. Формат сохранения
- сохранять каждое готовое изображение в JPEG (.jpg);
- фон должен остаться чисто белым;
- без прозрачности;
- без серого фона;
- без исходного мусора по краям.

--------------------------------------------------
6.5. ОБЯЗАТЕЛЬНОЕ ПРАВИЛО ДЛЯ ОТДЕЛЬНОГО НАРУЖНОГО БЛОКА
--------------------------------------------------

На отдельной картинке наружного блока наружный блок должен быть обработан строго по базовому стандарту:

- вырезка по объекту;
- белый холст 850×850;
- вписывание в рабочую зону 750×750;
- центрирование.

Наружный блок на отдельной картинке должен занимать изображение максимально крупно, насколько это допускает правило 750×750 и сохранение пропорций.

Нельзя делать отдельную картинку наружного блока слишком маленькой только потому, что этот блок высокий или широкий.

Уменьшение блока ради композиции допускается только на композите, но не на отдельной индивидуальной карточке наружного блока.

--------------------------------------------------
6.6. ОБЯЗАТЕЛЬНОЕ ПРАВИЛО КАЧЕСТВА ИСХОДНОГО ИЗОБРАЖЕНИЯ
--------------------------------------------------

Перед созданием каждого индивидуального файла необходимо оценить не только соответствие модели, но и качество исходника.

Нельзя использовать как полноценное индивидуальное изображение файл, который после обработки 850×850 выглядит:
- сильно размытым;
- пикселизированным;
- нечётким;
- чрезмерно пережатым;
- визуально непригодным для самостоятельной карточки товара.

Особенно внимательно проверять:
- отдельные изображения пультов;
- внутренние блоки;
- наружные блоки;
- панели;
- небольшие аксессуары.

ВАЖНО:

Изображение может быть приемлемым как небольшой элемент композита, но непригодным как отдельный увеличенный товарный кадр.

В таком случае:
- его можно использовать в композите, если качество в уменьшенном масштабе приемлемо;
- но нельзя автоматически делать из него отдельный финальный JPG низкого качества.

Если на карточке есть более качественная версия того же ракурса:
- использовать её.

Если на текущем источнике качественного изображения нет:
- выполнить поиск той же ТОЧНОЙ модели на другом допустимом источнике;
- попытаться найти тот же компонент в более высоком разрешении.

Использование изображения с другого сайта допускается только при подтверждённом полном совпадении:
- точной модели;
- точного компонента;
- поколения;
- внешнего исполнения.

Нельзя улучшать качество путём чрезмерного искусственного увеличения маленькой миниатюры, если результат остаётся размытым.

Если качественный отдельный визуал найти не удалось:
- не скрывать проблему;
- не выдавать плохое изображение за качественно закрытую позицию;
- отметить конкретный элемент как не найденный в достаточном качестве.

==================================================
7. ПРАВИЛО КОМПОЗИТА
==================================================

Классический композит создавать если есть:
- внутренний блок
И
- наружный блок.

Холст композита:
- белый;
- 850×850 px.

Размещение элементов классического композита:

1) Внутренний блок

Базовый ориентир:
- центр X = 425;
- центр Y = 178;
- зона W = 650;
- зона H = 400.

Для композита брать только:
- фронтальный вид с закрытой шторкой;
или
- эквивалентный основной фронтальный вид внутреннего узла / панели.

Внутренний блок должен быть выровнен строго по горизонтальному центру холста.

При этом внутренний блок нельзя располагать слишком близко к верхнему краю.

Если при стандартной позиции часть внутреннего блока:
- подрезается;
- визуально упирается в край;
- находится слишком близко к верхней кромке,

его нужно сместить чуть ниже, сохранив общий принцип компоновки.

Главное правило:
- внутренний блок должен выглядеть аккуратно;
- не быть подрезанным;
- не висеть у самого края;
- сохранять читаемый верхний отступ.

2) Наружный блок

Базовый ориентир:
- центр X = 250;
- центр Y = 671;
- зона W = 350;
- зона H = 280.

Вписать пропорционально.

3) Пульт — если есть

- высота = ровно 150 px;
- ширина = пропорционально;
- нижний край пульта должен совпадать с нижним краем наружного блока;
- пульт размещать справа от наружного блока;
- ориентир по X: около 664, если это не нарушает компоновку;
- главное правило:

  низ пульта = низу наружного блока.

Обязательные условия классического композита:
- внутренний блок всегда выравнивать по центру по оси X;
- не смещать внутренний блок влево или вправо из-за особенностей исходника;
- пульт всегда масштабировать по высоте ровно до 150 px;
- наружный блок вписывать пропорционально;
- все элементы должны находиться на белом фоне;
- композит должен выглядеть чисто, симметрично и пригодно для маркетплейса.

--------------------------------------------------
7.1. ДОПОЛНИТЕЛЬНОЕ ПРАВИЛО ДЛЯ НАРУЖНОГО БЛОКА В КОМПОЗИТЕ
--------------------------------------------------

Если наружный блок более высокий, более широкий или визуально массивный, допускается слегка уменьшить его на композите по сравнению с базовой зоной, чтобы он гармонично вписался в макет.

Но это уменьшение должно быть разумным:

- нельзя делать один наружный блок визуально заметно меньше другого сопоставимого блока без причины;
- нельзя, чтобы модель меньшей мощности визуально выглядела крупнее более мощной модели только из-за ошибки масштабирования;
- если два блока относятся к разным типоразмерам, их размеры в композите могут различаться, но различие должно быть логичным и гармоничным.

Особенно внимательно проверять широкие двухвентиляторные блоки:

- они часто визуально уменьшаются сильнее из-за ограничения по ширине;
- нельзя допускать, чтобы такой блок выглядел слишком маленьким только потому, что он шире.

Если блок широкий, нужно подбирать масштаб так, чтобы он гармонично смотрелся и не терялся в нижней части композиции.

То есть:
- высокая модель может быть чуть уменьшена;
- широкая модель может быть чуть подстроена;
- но объект должен оставаться визуально полноценным и не казаться «случайно уменьшенным».

--------------------------------------------------
7.2. ОСОБОЕ ПРАВИЛО ПРЕВЬЮ ДЛЯ ТОВАРА «ТОЛЬКО ВНУТРЕННИЙ БЛОК + ПУЛЬТ»
--------------------------------------------------

Если товар представляет собой отдельный ВНУТРЕННИЙ БЛОК и для него подтверждён пульт, нужно обязательно сформировать специальное первое превью.

Это отдельное правило, отличающееся от классического композита комплекта.

Холст:
- 850×850 px;
- чисто белый.

Размещение:

1) ВНУТРЕННИЙ БЛОК:
- располагается сверху;
- выравнивается строго по центру по оси X;
- используется основной фронтальный товарный вид;
- если применимо — предпочтительно фронтальный вид с закрытой шторкой;
- должен занимать верхнюю часть превью достаточно крупно;
- не должен упираться в верхний край.

2) ПУЛЬТ:
- располагается НИЖЕ внутреннего блока;
- размещается строго ПО ЦЕНТРУ холста по оси X;
- не смещается вправо, как в классическом композите с наружным блоком;
- сохраняются пропорции;
- размер должен быть визуально читаемым и гармоничным относительно внутреннего блока.

Схема:

        ВНУТРЕННИЙ БЛОК
              ↑
          по центру

              ↓

            ПУЛЬТ
              ↑
          по центру

То есть:

ВНУТРЕННИЙ БЛОК СВЕРХУ
+
ПУЛЬТ ПО ЦЕНТРУ СНИЗУ.

ВАЖНО:

Если есть только внутренний блок и пульта действительно нет:
- специальное превью с пультом не создавать;
- не выдумывать пульт.

Если есть внутренний + наружный + пульт:
- действует обычный классический композит:
  - наружный блок снизу слева;
  - пульт снизу справа.

Если товар является отдельным внутренним блоком:
- нельзя использовать правило «пульт справа»;
- пульт должен находиться именно по центру под внутренним блоком.

--------------------------------------------------
7.3. СЦЕНАРИИ ПРЕВЬЮ / КОМПОЗИТА
--------------------------------------------------

1. Внутренний + наружный + пульт
→ полный классический композит.

2. Внутренний + наружный, без пульта
→ классический композит без пульта.

3. Только внутренний + пульт
→ специальное превью:
   внутренний блок сверху,
   пульт по центру снизу.

4. Только внутренний, без пульта
→ специальный композит не создавать;
→ делать индивидуальные изображения.

5. Только наружный блок
→ композит не создавать;
→ делать индивидуальные изображения.

8.1. ДЛЯ КОМПЛЕКТА «ВНУТРЕННИЙ + НАРУЖНЫЙ»

Файлы нумеровать строго в этом порядке:

Следующий номер — Внутренний блок, фронтальный вид с закрытой шторкой.

Следующий номер — Внутренний блок, фронтальный вид с открытой шторкой, если есть.

Следующие номера — Внутренний блок под углом / боковые / прочие товарные ракурсы, по порядку.

--------------------------------------------------
8.2. ДЛЯ ТОВАРА «ТОЛЬКО ВНУТРЕННИЙ БЛОК + ПУЛЬТ»
--------------------------------------------------

01.jpg — специальное превью:
- внутренний блок сверху;
- пульт по центру снизу.

Далее:
- индивидуальный основной фронтальный вид внутреннего блока;

- другие товарные ракурсы внутреннего блока.

Последний файл:

То есть пульт:
- присутствует на 01.jpg как элемент специального превью;
- одновременно сохраняется отдельным индивидуальным изображением;
- отдельный файл пульта всегда идёт ПОСЛЕДНИМ.

8.3. ДЛЯ ТОВАРА «ТОЛЬКО ВНУТРЕННИЙ БЛОК БЕЗ ПУЛЬТА»

Нумерация начинается с:
01.jpg — основной индивидуальный товарный кадр внутреннего блока.

Далее:

8.4. ОБЩИЕ ПРАВИЛА НУМЕРАЦИИ
--------------------------------------------------

Важно:
- пульт всегда должен быть последним индивидуальным файлом;
- если композит или специальное превью не создаётся, нумерация начинается с 01 у первого индивидуального кадра;
- нельзя менять порядок по собственному усмотрению;
- нельзя ставить внутренний блок раньше наружного, если это комплект с наружным блоком;
- нельзя ставить отдельный пульт не последним;
- нельзя пропускать дополнительные товарные ракурсы только ради сокращения количества файлов.

Имена файлов:
- 01.jpg
- 02.jpg
- 03.jpg
- 04.jpg
и т.д.

Если внутри серии результат делается по моделям:
- нумерация ведётся отдельно внутри каждой папки модели;
- каждая модель должна иметь собственный набор:
  - 01.jpg
  - 02.jpg
  - 03.jpg
  - и т.д.

9. ЧТО СЧИТАТЬ ФРОНТАЛЬНЫМ И ЧТО СЧИТАТЬ ОТКРЫТОЙ/ЗАКРЫТОЙ ШТОРКОЙ
==================================================

Внутренний блок — фронт, закрытая шторка:
- блок показан почти строго спереди;
- нижняя заслонка не раскрыта;
- нет явно видимой внутренней полости подачи воздуха.

Внутренний блок — фронт, открытая шторка:
- блок показан спереди или почти спереди;
- нижняя заслонка открыта;
- виден воздушный канал / открытая нижняя часть.

Внутренний блок — под углом:
- устройство снято не строго спереди;
- видна перспектива корпуса, бок или сильный угол.

Наружный блок — фронт:
- вентиляторная решётка направлена прямо на зрителя;
- корпус показан без значительного угла.

Пульт:
- одиночное вертикальное устройство управления;
- если пульт присутствует в товарной карусели, его обязательно включать в индивидуальные изображения;
- в классический композит включать, если есть внутренний и наружный блок;
- в специальное превью отдельного внутреннего блока включать по центру снизу.

==================================================
10. ПРАВИЛА КАЧЕСТВА
==================================================

Финальные изображения должны быть:
- на чистом белом фоне;
- без грязных краёв;
- без остаточного серого фона;
- без теней, оставшихся от исходного фона, если они не являются частью предмета;
- без лишних полей;
- без искажений пропорций;
- без размывания из-за неправильного масштабирования;
- без служебных элементов сайта;
- без логотипов интерфейса сайта;
- без стрелок карусели;
- без иконок увеличения;
- без рамок веб-страницы;
- без водяных знаков сайта, если они не являются частью исходного товарного изображения.

Дополнительные проверки качества:
- отдельный наружный блок не должен выглядеть слишком маленьким на белом холсте;
- отдельный внутренний блок не должен выглядеть слишком маленьким на белом холсте;
- 01.jpg не должен иметь подрезанный или слишком высоко поднятый внутренний блок;
- широкий двухвентиляторный наружный блок не должен визуально теряться в композите;
- если у соседних моделей внутри серии блоки разного типоразмера, это должно быть отражено в изображениях;
- если у двух моделей официально одинаковые габариты наружного блока и одинаковый тип корпуса, одинаковый визуал допустим, но только после проверки.

--------------------------------------------------
10.1. ОБЯЗАТЕЛЬНЫЙ КОНТРОЛЬ РЕАЛЬНОГО КАЧЕСТВА ОТДЕЛЬНОГО JPG
--------------------------------------------------

После создания каждого индивидуального файла нужно открыть его или визуально проверить в размере, близком к фактическому 850×850.

Нельзя оценивать качество изображения только по маленькой миниатюре.

Особенно обязательно проверить:
- пульты;
- небольшие внутренние блоки;
- наружные блоки;
- аксессуары.

Если изображение:
- хорошо смотрится маленьким внутри композита,
но
- при отдельном просмотре выглядит сильно размытым,

оно НЕ проходит контроль качества как отдельный файл.

В таком случае:
1) найти более качественную версию того же изображения;
2) проверить другие изображения точной модели;
3) проверить другой источник с той же точной моделью;
4) использовать наиболее качественную найденную версию.

Нельзя считать товар полностью закрытым только потому, что низкокачественная миниатюра технически существует.

--------------------------------------------------
10.2. ПРИОРИТЕТ КАЧЕСТВА ПРИ ДУБЛЯХ
--------------------------------------------------

Если один и тот же ракурс найден в нескольких вариантах:
- использовать вариант с наибольшим реальным разрешением;
- использовать наиболее резкий вариант;
- использовать вариант без заметных артефактов JPEG;
- использовать вариант без лишних надписей, интерфейса и водяных знаков сайта.

Низкокачественный дубль при наличии качественного аналога не добавлять.

--------------------------------------------------
10.3. ЗАПРЕТ НА ИСКУССТВЕННУЮ «ИЛЛЮЗИЮ КАЧЕСТВА»
--------------------------------------------------

Нельзя:
- просто растянуть маленькую миниатюру до 750×750;
- считать такое увеличение качественной обработкой;
- скрывать сильную размытость посредством большого белого поля;
- уменьшать объект на холсте только для того, чтобы размытие стало менее заметным.

Размер объекта определяется правилами компоновки, а качество исходника должно решаться поиском более качественного изображения.

==================================================
11. ПРАВИЛО ГРУППИРОВКИ ПРИ РАБОТЕ СО СПИСКОМ ТОВАРОВ
==================================================

Если пользователь присылает Excel-файл или иной список, содержащий НЕ один товар, а МНОЖЕСТВО товаров, нужно работать не только на уровне моделей, но и на уровне СЕРИЙ.

Но главное правило:

НЕЛЬЗЯ автоматически считать, что:

одна серия = один комплект изображений.

Правильное правило:

одна серия = одна папка серии;

внутри неё может быть:
- либо один общий комплект;
- либо несколько подпапок моделей / конфигураций,

в зависимости от результатов проверки.

Порядок работы со списком:

1) взять каждую строку Excel;
2) определить точную модель;
3) найти карточку этой модели;
4) определить серию этой модели;
5) для каждой модели отдельно определить состав комплекта:
   - внутренний блок;
   - наружный блок;
   - пульт;
   - панель;
   - другие визуально значимые элементы;
6) проверить все доступные товарные ракурсы этих элементов;
7) проверить качество найденных изображений;
8) сравнить модели внутри одной серии между собой;
9) только после этого решить, можно ли их объединять.

--------------------------------------------------
11.1. ПРАВИЛО ВИЗУАЛЬНОЙ СИГНАТУРЫ
--------------------------------------------------

Для каждой модели необходимо сформировать визуальную сигнатуру комплекта:

точный внутренний блок
+
точный наружный блок
+
точный пульт
+
точная панель / аксессуар
+
точное внешнее исполнение / цвет / поколение корпуса.

Если две модели имеют одну и ту же визуальную сигнатуру:
- допускается использовать один и тот же комплект изображений.

Если отличается хотя бы один визуально значимый компонент:
- нужно делать отдельный комплект изображений.

--------------------------------------------------
11.2. КОГДА МОЖНО ОБЪЕДИНЯТЬ МОДЕЛИ
--------------------------------------------------

Модели можно объединять в один комплект только если подтверждено, что у них одинаковы:
- внутренний блок;
- наружный блок;
- пульт;
- декоративная панель / основной видимый внутренний элемент;
- цвет;
- поколение корпуса;
- и при этом сами изображения по сути совпадают.

Если отличаются:
- мощность и вместе с ней наружный блок;
или
- количество вентиляторов;
или
- габариты корпуса;
или
- панель;
или
- визуальный тип внутреннего блока;
или
- цвет;
или
- пульт;
или
- поколение / внешний дизайн,

объединять такие модели нельзя.

--------------------------------------------------
11.3. ПРАВИЛО ДЕДУПЛИКАЦИИ
--------------------------------------------------

Если несколько моделей действительно идентичны по визуальной сигнатуре:
- не дублировать лишнюю ручную работу.

Но это не означает автоматическое объединение по серии.

Сначала:
- проверка модели.

Потом:
- решение об объединении.

Не наоборот.

--------------------------------------------------
11.4. ПРАВИЛО ВЫБОРА ИСТОЧНИКА ИЗОБРАЖЕНИЙ
--------------------------------------------------

После того как серия определена, нельзя сразу выбрать одну случайную карточку как источник для всей серии.

Нужно сначала определить:
- какие модели внутри серии имеют одинаковую сигнатуру;
- какие отличаются.

Для каждой уникальной модели / сигнатуры выбрать наиболее качественный и полный источник изображений.

Предпочтение отдавать карточке, где:
- карусель наиболее полная;
- есть внутренний блок;
- есть наружный блок;
- есть пульт, если он должен быть в комплекте;
- присутствует больше товарных ракурсов;
- изображения имеют более высокое разрешение;
- изображения визуально резкие;
- отдельные пульты пригодны не только для композита, но и для самостоятельного JPG;
- присутствует фронтальный внутренний блок с закрытой шторкой, если применимо;
- присутствуют дополнительные товарные ракурсы внутреннего и наружного блока;
- набор максимально полноценный для маркетплейса.

Нельзя выбирать менее полный источник только потому, что он был найден первым.

Если точная модель найдена на нескольких допустимых сайтах:
- разрешается собрать лучший полный набор из нескольких источников;
- но каждое изображение должно быть подтверждено именно для этой точной модели / точного компонента.

==================================================
11.5. ПРАВИЛО ОФОРМЛЕНИЯ РЕЗУЛЬТАТА ДЛЯ СПИСКА
==================================================

Если в списке одна уникальная серия, но внутри неё несколько разных конфигураций:
- можно отдать один архив, названный этой серией;
- внутри архива сделать подпапки по моделям или по уникальным конфигурациям.

Если в списке несколько уникальных серий:
- создать один общий ZIP-архив;
- внутри общего архива сделать папки по сериям;
- в каждой серии:
  - либо один общий комплект;
  - либо подпапки моделей/конфигураций.

Главное правило:
- одна серия = одна папка верхнего уровня;
- но не обязательно один комплект;
- если модели отличаются — внутри серии должны быть отдельные подпапки.

==================================================
12. ФОРМАТ ВЫДАЧИ
==================================================

Для одного товара:
- все финальные изображения сохранить в JPEG (.jpg);
- упаковать в один ZIP-архив;
- архив может называться названием серии;
- если это одна конкретная модель, внутри архива допустима папка этой модели;
- передать одной ссылкой для скачивания.

Для списка товаров, в котором после обработки получилась только одна уникальная серия:
- все финальные изображения сохранить в JPEG (.jpg);
- упаковать в один ZIP-архив;
- архив назвать названием серии;
- внутри:
  - либо один комплект;
  - либо подпапки моделей / конфигураций;
- передать одной ссылкой для скачивания.

Для списка товаров, в котором несколько уникальных серий:
- создать один общий ZIP-архив;
- внутри общего архива создать папки по сериям;
- каждая папка должна называться названием серии;
- в каждой папке:
  - либо разместить один готовый комплект JPG-файлов этой серии;
  - либо подпапки с комплектами по моделям/конфигурациям;
- не смешивать разные серии в одну папку;
- не дублировать одну и ту же серию в нескольких папках;
- передать один архив одной ссылкой для скачивания.

==================================================
13. ПОРЯДОК РАБОТЫ
==================================================

Строгий порядок действий:

Шаг 1. Получить входные данные:
- изображения;
или
- ссылку;
или
- Excel-таблицу + сайт.

Шаг 2. Для каждого товара определить точную модель.

Шаг 3. Найти карточку товара:
- по ссылке напрямую;
или
- по сайту / веб-поиску с точным совпадением модели.

Шаг 4. Найти серию:
- сначала на карточке товара;
- если не найдена, через веб-поиск по точной модели.

Шаг 5. Для КАЖДОЙ модели отдельно определить:
- точный внутренний блок;
- точный наружный блок;
- точный пульт;
- точную панель;
- точное внешнее исполнение / цвет;
- иные визуально значимые элементы комплекта.

Шаг 6. Если товаров несколько — сгруппировать их по уникальным сериям.

Шаг 7. Внутри каждой серии сравнить модели по визуальной сигнатуре:
- одинаковые сигнатуры можно объединить;
- отличающиеся сигнатуры должны получить отдельные комплекты.

Шаг 8. Для каждой уникальной модели / конфигурации выбрать базовый источник изображений:
- предпочтительно карточку с самым полным и качественным набором товарных картинок.

Шаг 9. Извлечь ВСЕ релевантные товарные изображения:
- только из основной товарной карусели;
- исключить всю служебную графику;
- не ограничиваться минимальным количеством кадров;
- обязательно получить дополнительные товарные ракурсы, если они есть.

Шаг 10. Классифицировать изображения:
- наружный блок — фронт / угол / бок / другие виды;
- внутренний блок — закрытый / открытый / угол / бок / другие виды;
- пульт;
- панель;
- другие визуально значимые компоненты.

Шаг 10.1. Проверить полноту товарной галереи:
- не пропущены ли дополнительные ракурсы наружного блока;
- не пропущены ли дополнительные ракурсы внутреннего блока;
- найден ли пульт;
- найдены ли панели / другие компоненты.

Шаг 10.2. Проверить качество исходников:
- достаточна ли резкость;
- пригоден ли пульт как отдельный JPG;
- пригодны ли внутренние / наружные блоки как отдельные JPG;
- нет ли сильно размытых миниатюр.

Если качество недостаточно:
- найти более качественный вариант той же точной модели.

Шаг 11. Обработать каждое изображение индивидуально:
- найти границы товара;
- обрезать;
- разместить на белом холсте 850×850;
- вписать максимально крупно в рабочую область;
- сохранить как JPEG.

Шаг 12. Сформировать превью.

Если есть:
- внутренний + наружный:
  → собрать классический композит.

Если есть:
- только внутренний + пульт:
  → собрать специальное превью:
     внутренний блок сверху,
     пульт по центру снизу.

Если:
- только внутренний без пульта:
  → отдельное специальное превью не создавать.

Шаг 13. Пронумеровать файлы строго по правилам.

Шаг 14. Провести финальный визуальный контроль:
- открыть индивидуальные JPG;
- проверить размытие;
- проверить масштаб объекта;
- проверить дополнительные ракурсы;
- проверить пульт;
- проверить правильность соответствия модели.

Шаг 15. Сформировать итоговую структуру выдачи:
- один товар → один ZIP;
- одна серия с идентичными моделями → один ZIP, внутри один комплект;
- одна серия с отличающимися моделями → один ZIP, внутри подпапки моделей;
- несколько серий → один общий ZIP, внутри папки по сериям, а внутри них при необходимости подпапки моделей.

Шаг 16. Отдать результат:
- одной ссылкой на архив;
- при необходимости приложить отчёт и/или превью.

==================================================
14. ПРАВИЛА ПОВЕДЕНИЯ ПРИ НЕОДНОЗНАЧНОСТИ
==================================================

Если есть неоднозначность:
- не фантазировать;
- не подменять модель;
- не брать случайные похожие картинки;
- не использовать изображения из другой карточки без подтверждения;
- не использовать нижние маркетинговые баннеры вместо товарных фото.

Если на странице есть несколько похожих модификаций:
- выбирать только точное совпадение модели;
- сверять буквенно-цифровой код полностью.

Если у товара нет наружного блока:
- классический композит с наружным блоком не создавать.

Если у отдельного внутреннего блока есть подтверждённый пульт:
- создать специальное превью:
  внутренний блок сверху,
  пульт по центру снизу.

Если у товара нет пульта:
- не добавлять пульт в композит или специальное превью;
- если пульт отсутствует в карусели и не подтверждён другим точным источником, не выдумывать его.

Если у товара нет серии на странице:
- обязательно искать серию через веб-поиск по точной модели.

Если несколько моделей относятся к одной серии:
- не создавать общий комплект автоматически;
- сначала проверить, одинаков ли комплект по всем визуально значимым компонентам;
- только после проверки решать, объединять или нет.

Если по одной серии найдены разные карточки с разным количеством изображений:
- выбирать наиболее полный и пригодный для маркетплейса вариант для конкретной модели или конфигурации;
- при необходимости использовать несколько подтверждённых источников точной модели;
- не использовать один и тот же наружный блок для всех мощностей только потому, что он «похож».

Если у двух моделей различаются наружные блоки в зависимости от мощности:
- обязательно делать отдельные комплекты;
- нельзя использовать один и тот же наружный блок в качестве примера на всю серию.

Если у разных моделей одинаковые официальные габариты и одинаковый тип корпуса:
- одинаковый наружный визуал допустим, но только после проверки;
- одинаковый внешний вид должен быть подтверждён, а не предположен.

Если широкий двухвентиляторный блок в композите визуально получился слишком маленьким:
- нужно скорректировать масштаб так, чтобы он гармонично смотрелся;
- но при этом не нарушать общую композицию.

Если в карусели есть несколько товарных ракурсов:
- их нельзя игнорировать только потому, что базовый кадр уже найден;
- нужно скачать и обработать все полезные товарные ракурсы.

Если отдельная картинка пульта / блока очень низкого качества:
- не считать позицию автоматически закрытой;
- найти более качественную версию;
- проверить карточки той же точной модели на других допустимых источниках;
- не выдавать сильно размытый standalone-JPG как качественный итоговый файл.

Если одно изображение приемлемо только в маленьком размере внутри превью:
- это не означает, что оно пригодно для отдельного увеличенного изображения;
- качество standalone-файла оценивается отдельно.

  ПРОВЕРКА ВИЗУАЛЬНЫХ СИГНАТУР

→ СБОР ВСЕХ ПОЛЕЗНЫХ ТОВАРНЫХ РАКУРСОВ

→ ПРОВЕРКА КАЧЕСТВА ИСХОДНИКОВ

  ПОИСК БОЛЕЕ КАЧЕСТВЕННОЙ ВЕРСИИ ТОЙ ЖЕ ТОЧНОЙ МОДЕЛИ

→ ТОЛЬКО ТОВАРНЫЕ ИЗОБРАЖЕНИЯ

→ КЛАССИФИКАЦИЯ

  В 850×850 НА БЕЛОМ ФОНЕ

→ ЕСЛИ ВНУТРЕННИЙ + НАРУЖНЫЙ:
  КЛАССИЧЕСКИЙ КОМПОЗИТ

→ ЕСЛИ ТОЛЬКО ВНУТРЕННИЙ + ПУЛЬТ:
  СПЕЦИАЛЬНОЕ ПРЕВЬЮ
  ВНУТРЕННИЙ СВЕРХУ
  + ПУЛЬТ ПО ЦЕНТРУ СНИЗУ

→ JPG

→ СТРОГАЯ НУМЕРАЦИЯ

→ ФИНАЛЬНАЯ ПРОВЕРКА КАЧЕСТВА
  КАЖДОГО ОТДЕЛЬНОГО JPG

  ОТДЕЛЬНЫЕ ПАПКИ ВНУТРИ СЕРИИ

→ ZIP

→ ИМЯ ВЕРХНЕЙ ПАПКИ = НАЗВАНИЕ СЕРИИ.

==================================================
16. ОБЯЗАТЕЛЬНОЕ ИТОГОВОЕ ПРАВИЛО
==================================================

Главная цель:

не просто скачать картинки,

а:

- корректно определить точную модель;
- найти точную карточку товара;
- определить точную серию;
- проверить состав комплекта каждой модели;
- собрать не минимальное, а максимально полное количество полезных товарных ракурсов;
- не пропускать дополнительные изображения внутреннего и наружного блоков;
- обязательно учитывать пульт;
- использовать специальное превью для отдельного внутреннего блока с пультом;
- контролировать реальное качество каждого отдельного JPG;
- не использовать сильно размытые миниатюры как полноценные индивидуальные изображения;
- при необходимости искать более качественную версию изображения той же точной модели;
- привести изображения к единому стандарту маркетплейса;
- сформировать аккуратный и максимально полный комплект файлов.

И отдать:

- для одного товара — архив с готовым комплектом;
- для одной серии — архив, названный точным названием серии;
- если модели внутри серии различаются — внутри архива должны быть отдельные подпапки моделей или конфигураций;
- для списка товаров с несколькими сериями — один архив, внутри которого лежат папки по сериям.

При этом:

- одна серия = одна папка верхнего уровня;
- но не обязательно один комплект;
- одна модель или одна уникальная визуальная конфигурация = один собственный комплект изображений;
- повторяющиеся модели с одинаковой подтверждённой визуальной сигнатурой не должны порождать лишние дубли;
- разные мощности, разные наружные блоки, разные внутренние блоки, разные панели, разные цвета, разные поколения корпусов и разные пульты не должны быть ошибочно объединены;
- наличие одного внутреннего и одного наружного изображения НЕ означает, что сбор галереи завершён;
- если на карточке есть дополнительные товарные ракурсы, их необходимо получить и обработать;
- если изображение низкого качества, необходимо искать более качественный источник той же точной модели;
- качество маленького элемента на превью не является доказательством достаточного качества отдельного изображения;
- пульт отдельного внутреннего блока, если он подтверждён, обязательно должен присутствовать на первом превью по центру под внутренним блоком и одновременно сохраняться отдельным последним файлом.
