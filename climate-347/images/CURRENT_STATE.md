## Неподлежащие компромиссу правила
Для наружных блоков проверять каждую модель, мощность, точный корпус, габариты, число/расположение вентиляторов, число модулей, цвет/поколение и зимнее исполнение; серия не заменяет модель. Не использовать чужой корпус. Идентичные изображения только при доказанной идентичности исполнения. Точный источник + визуальная проверка + полная галерея + качество v11, иначе OPEN. Не считать размеры из Excel заводским доказательством. Стандарт 850×850, рабочая зона 750×750, чистый белый фон, исходные пропорции, JPEG, композит и нумерация строго v11. Вся работа выполняется текущим сеансом, этапы фиксируются на GitHub с проверкой результата. Бинарные исходники и ZIP пока вне GitHub, Releases недоступен через текущий интерфейс; не придумывать публичные ссылки.
