## Технический вывод из архивных JS

В сохранённом JavaScript интерфейса товара обработчик клика по PDF берёт адрес из `e.url || e.document?.p`, после чего формирует ссылку с `target="_blank"`. Значит, **клик по плитке на живом сайте должен передавать URL PDF**, если поле URL присутствует в данных API. Но в локально сохранённом HTML присутствуют только названия и размеры плиток; в их DOM нет `href`. Поэтому URL нельзя надёжно восстановить только из статического HTML этой страницы.

Всякая обработка по MIXED: **только видимая целевая карточка**, скрытые дубликаты других моделей игнорировать, распознавать версии/исполнения документов; статус `DISCOVERED` не равен `DOWNLOADED` или `OEM_VERIFIED`.
